# Ruhuna CLI 🚀

A lightweight command-line utility tool built by a Computer Science student at the University of Ruhuna. It helps automate student tasks directly from the terminal.

## Features
- **Welcome Greeting:** Personalized CLI startup greeting with terminal styling.
- **Quick Links:** Instantly launches official university portals in your web browser.
- **GPA Calculator:** Quickly calculates estimated semester GPAs based on credits and grade points.

## Tech Stack
- **Python**
- **Typer** (CLI framework)
- **Rich** (Terminal formatting and tables)
